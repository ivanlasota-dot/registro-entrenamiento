REGISTRO FUNCIONAL V6 - INSTALACIÓN EN GITHUB PAGES

1. En github.com, crea un repositorio PÚBLICO (por ejemplo: registro-entrenamiento).
2. En el repositorio, selecciona Add file > Upload files.
3. Sube los CINCO archivos de esta carpeta a la RAÍZ del repositorio: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png. No subas tus respaldos JSON.
4. Confirma los cambios (Commit changes).
5. Settings > Pages > Build and deployment > Deploy from a branch. Selecciona main y /(root), y guarda.
6. Espera a que GitHub muestre el enlace: https://TU_USUARIO.github.io/registro-entrenamiento/
7. Abre el enlace en Chrome de Android. Menú ⋮ > Instalar aplicación o Añadir a pantalla de inicio.
8. Abre la aplicación, registra una prueba, ciérrala, pon modo avión y vuelve a abrirla para comprobar que funciona sin conexión.
9. Para llevar tus datos antiguos al móvil, exporta JSON en la aplicación anterior e impórtalo en esta.

IMPORTANTE: GitHub Pages publica el CÓDIGO de la aplicación. Los registros se guardan localmente en cada navegador/dispositivo. No subas ningún respaldo JSON al repositorio. Exporta respaldos regularmente. La app no sincroniza entre dispositivos.
